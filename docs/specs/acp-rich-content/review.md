**Fix stage.** Every bug and warning is fixed or rejected with its reason; 13 nits stay open, fixed only where

## Dropped after checking

- **Tool arguments reaching the journal on an update.** `ToolMessage` does not carry `Input`, so the dataset is
  not in the tool row.
- **`ResizeObserver` calling `chart.resize()`** (layout read per resize). The callback runs after layout; not a
  defect.
- **Four `style={{…}}` object bindings.** No breakage found; `main` has the same pattern.
- **`StubHandler` duplicating `ContentTypeHandler`.** The two stubs record different things.
- **Flush starvation in `AgentPaneOutput.Buffered`.** Every block write is preceded by a row, so the reschedule
  branch is not reached repeatedly.
